本子库旨在为小白介绍 Windows 系统的日常使用，包括系统设置、文件管理、内置工具与效率技巧。结合仓库定位（准大学生从 0 入门电脑）与其他子库的分工（软件记管安装卸载、维护记管重装清理、上网记管浏览器网络），《使用记》聚焦“Windows 系统本身怎么用”。仓库所有者目前构思了以下几篇文章标题：

- 《认识 Windows 与初次设置》：Windows 是什么、首次开机设置流程（微软账户登录、隐私选项）、桌面与开始菜单入门、系统更新的意义
- 《文件管理与资源管理器》：盘符与分区、文件路径概念、资源管理器基本操作（复制/移动/重命名/多选）、快速访问与搜索（含 Everything 推荐）
- 《Windows 常用内置工具》：截图（Win+Shift+S）、录屏（Win+G）、任务管理器（打开方式与基础查看）、记事本/画图/计算器等小工具、Windows Terminal 简介
- 《窗口、多任务与快捷键》：窗口排列（Win+方向键）、虚拟桌面（Win+Tab）、Alt+Tab 切换、剪贴板历史（Win+V）、高频快捷键合集
- 《系统设置与个性化》：显示设置（分辨率/缩放/夜间模式）、深色模式与主题、默认应用设置、通知与专注助手、电源与睡眠
- 《开机启动项与后台程序管理》：任务管理器启动项管理、识别并关闭不必要的后台进程、警惕全家桶软件常驻
- 《使用 Windows 的常见坑与效率技巧》：不下载“优化/清理大师”、不乱删 C 盘文件、输入法切换技巧、OneDrive 云同步简介
