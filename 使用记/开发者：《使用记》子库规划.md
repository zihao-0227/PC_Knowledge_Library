本子库旨在为小白介绍 Windows 系统的日常使用，包括系统设置、文件管理、内置工具与效率技巧。结合仓库定位（准大学生从 0 入门电脑）与其他子库的分工（软件记管安装卸载、维护记管重装清理、上网记管浏览器网络），《使用记》聚焦“Windows 系统本身怎么用”。仓库所有者目前构思了以下几篇文章标题：

- 《认识 Windows 与初次设置》：Windows 是什么（操作系统概念，与 macOS/Linux 的简单对比）；首次开机设置流程（区域与键盘布局、联网、微软账户登录——为什么要登录、本地账户与微软账户的区别、隐私选项：诊断数据与广告 ID）；桌面入门（桌面图标、任务栏、开始菜单、通知中心、系统托盘）；系统更新的意义（什么是更新、为什么重要、如何手动检查更新）
- 《文件管理与资源管理器》：盘符与分区（C 盘是系统盘、软件为什么不建议装 C 盘）；文件路径概念（盘符:\\文件夹\\文件、常见位置：桌面/文档/下载）；资源管理器基本操作（新建文件夹、复制/剪切/粘贴、多选 Ctrl/Shift、重命名 F2、拖拽移动）；快速访问与搜索（固定常用文件夹、使用搜索框、Everything 类工具推荐）；文件扩展名（显示扩展名、常见类型 .docx/.pdf/.exe 及其含义）
- 《Windows 常用内置工具》：截图（Win+Shift+S 区域截图、截图工具、PrintScreen 全屏）；录屏（Win+G Xbox Game Bar、更专业的 OBS 简介）；任务管理器（Ctrl+Shift+Esc 打开、进程/性能/启动选项卡、如何结束卡死程序）；小工具盘点（记事本、画图、计算器、录音机）；终端入门（cmd 与 PowerShell 是什么、如何打开、能拿来干嘛）
- 《窗口、多任务与快捷键》：窗口操作（最大化/最小化/关闭、Win+方向键分屏）；虚拟桌面（Win+Tab 创建与切换、Win+Ctrl+方向键）；Alt+Tab 切换窗口、Win+数字键切换任务栏应用；剪贴板历史（Win+V 的开启与使用）；高频快捷键合集（Ctrl+C/V/X/Z、Win+D 显示桌面、Win+E 打开资源管理器、Win+L 锁屏、Win+I 设置）
- 《系统设置与个性化》：显示设置（分辨率、缩放比例、夜间模式/护眼）；个性化（壁纸、主题、深色模式、锁屏画面）；默认应用设置（默认浏览器、默认播放器、默认看图软件）；通知与专注助手（通知权限管理、专注时段）；电源与睡眠（睡眠/关机区别、接通电源时的行为设置）
- 《开机启动项与后台程序管理》：启动项管理（任务管理器→启动选项卡、禁用不必要的开机自启）；后台进程识别（常见进程有哪些、如何判断异常进程）；警惕全家桶软件常驻（2345 系列、电脑管家类软件开机自启与弹窗问题）；通知与弹窗的来源排查
- 《使用 Windows 的常见坑与效率技巧》：不下载“优化/清理大师”（系统自带工具已够用，这类软件反而拖慢电脑）；不乱删 C 盘文件（常见误区，C 盘空间不足的正确处理方式——引导到维护记）；输入法切换技巧（中英切换、候选词翻页、手写/语音输入）；OneDrive 云同步简介（文件自动备份、跨设备同步、注意同步文件夹位置）
