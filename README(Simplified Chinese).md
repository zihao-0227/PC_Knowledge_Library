你好，欢迎来到这里。

智能手机时代，许多计算机上繁琐的操作已经被简化了。但，计算机依然是高性能工作的得力工具；计算机依旧是许多大学生必不可少的工具之一。可是，由于后代们是在智能手机时代的环境下长大的，这就导致一个极为尴尬的现象：***年轻一代已经越来越不懂得如何使用电脑了***。

这个仓库将一个准大学生在从购买到使用再到维护的顺序讲解与解答如何从0入门电脑。

## 仓库架构

| 分类      | 说明                               |
| ------- | -------------------------------- |
| **购买记** | 介绍计算机硬件、操作系统、软件的概念，同时提供了验机指导     |
| **使用记** | 介绍如何使用 Windows，包括系统软件、设置调整等      |
| **上网记** | 介绍常见的浏览器、搜索引擎以及常见网络概念，以及提升网络安全意识 |
| **软件记** | 介绍如何安装、使用、卸载软件，以及软件推荐            |
| **维护记** | 介绍重装系统、C盘清理等常用技能                 |
| **维修记** | （正在评估其合理性）                       |

> [!TIP] 
> 文章持续更新中，各分类的「子库规划」文件展示了该分类未来的内容方向。欢迎关注更新！
