# Hello,New Contributor👋

To contribute for this repository,here are some way to contribute:

- Write article(s) ***(recommend)***
- Build up GitHub the Pages ***(recommend)***
- Translation
- Submit error(s) and good idea(s)
- More……

## Write Article(s)

Click here to create a new branch or PR.👇

[![![GitHub branches|77](https://badgen.net/github/branches/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library) | [![GitHub open-pull-requests](https://badgen.net/github/open-prs/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library/pulls?q=is%3Aopen+is%3Apr)

If you want to add article(s),just create a new branch.Then writing article(s) on your branch.

> [!NOTE] 
> For the branch name,we advice you name as:***`New_Article(s)/<what new>`*** or just ***`NA/<what new>`*** .It will help administrators distinguish different type of contribute.

When you finish,create a new PR.Repository administrators will verifies you article(s),guidance a little change and merge you article(s).

> [!TIP] 
> In each folders,we add an article call `开发者：《XXX》子库规划`，you can follow this guidance to create a new article(s).

## Build Up The GitHub Pages

Click here to create a new fork or PR.👇

 [![GitHub forks](https://badgen.net/github/forks/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library/network) | [![GitHub open-pull-requests](https://badgen.net/github/open-prs/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library/pulls?q=is%3Aopen+is%3Apr)

This repository's GitHub Pages just getting started,so it's very simple.If you are good at build up GitHub Pages,you can create a fork,build up GitHub Pages on your fork.

When you finish build up,create a new PR.PR title should mention this PR is about the GitHub Pages changed.Then repository administrators will verifies you changed and give you advises.After that,we will merge you changed.

## Translation

Click here to create a new branch or PR.👇

[![![GitHub branches|77](https://badgen.net/github/branches/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library) | [![GitHub open-pull-requests](https://badgen.net/github/open-prs/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library/pulls?q=is%3Aopen+is%3Apr)

This project ending goal is try its best to help more computer newbies getting started of computer.To reach this goal,we also need some translators form Chinese to different kinds of languages.

Translation contribute reference to Write article(s):create a branch,translation,create a PR.Then we will review you contribute.

> [!NOTE] 
> For the branch name,we advice you name as:***`Translation/<Which language>/<which file(s)>`***  .It will help us distinguish different type of languages and articles.

## Submit Error(s) And Good Idea(s)

Click here to create a new issues or discussion.👇

[![GitHub issues|90](https://img.shields.io/github/issues/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library/issues) | [![GitHub discussions|115](https://img.shields.io/github/discussions/zihao-0227/PC_Knowledge_Library)](https://github.com/zihao-0227/PC_Knowledge_Library/discussions)

### For Error(s)

If you find any factual error(s) in reading any article,you can create a issues,add a ***bug*** label(We will custom the Labels part suitable for knowledge base soon).We will check and verify quickly.

### For Good Idea(s)

If you have any good idea(s),you can create a discussion,choices the Ideas categories.We'll evaluate you a genius idea,and apply to our repository.
