# 什么是浏览器

想象一下，互联网是一个没有边界的超级图书馆，图书馆为了方便管理，每一本书的书架都有它特殊的编号（如百度的www.baidu.com，B站的www.bilibili.com），为了方便省事以及存下更多的内容，所有书都用了一种特殊语言存了下来（小白看不懂的机器语言）。

如果你选择独自在这个图书馆里漫游，那么你就要解决这几个问题：

- 牢记每一本书的完整的书架编号和图书编号（如完整背下以下B站视频地址：https://www.bilibili.com/video/BV1GJ411x7h7）
- 花大量的时间学习机器语言来了解网页讲述了什么东西

举个例子，https://www.bilibili.com/video/BV1GJ411x7h7的开发者模式界面长这样：

![开发者模式下的网页](../引用图片/上网记/介绍常见浏览器/开发者模式下的网页.png)

为了解决这两个问题，人们开发了浏览器，它可以帮助用户：

- 按照完整的书架编号和图书编号找到书，也就是你想浏览的内容
- 将机器语言翻译成用户看得懂的语言，也就是渲染网页

通过浏览器你就可以看懂网页上的内容是什么。就比如上文的B站网页，经过浏览器渲染的结果是这样的，我们才知道我们被骗了😵‍💫

# 目前市面上常见的浏览器

目前主流的浏览器其实就这四家：Google Chrome、Microsoft Edge、Mozilla Firefox、Apple Safari。其他的浏览器大多基于这四家的内核（也就是浏览器的核心引擎）换了一层皮。接下来煮包来分别介绍一下它们。

## Google Chrome——浏览器界最严厉的父亲

![Google Chrome](../引用图片/上网记/介绍常见浏览器/Google_Chrome.jpg)

Google Chrome是由谷歌公司开发的网页浏览器。Chrome 是目前全世界使用人数最多的浏览器，市场占有率常年保持在 60% 以上。它最大的特点就是**快**——打开网页的速度确实很快，而且 Google 自家的服务（如 Gmail、Google 搜索、YouTube）在上面体验是最好的。

同时，Chrome 的**扩展生态是最丰富**的，不论是广告拦截、翻译、密码管理还是开发者工具，Chrome 应用商店里的扩展种类和数量都是最多的。如果你不知道用什么浏览器，选 Chrome 基本上不会出错。

不过 Chrome 有个缺点：**特别吃内存**。如果你一次开了十几个标签页，电脑的内存占用会蹭蹭往上飙。如果你的电脑内存只有 8GB 的话，Chrome 可能会让你的电脑卡成 PPT。

还有，如果你不会“科学上网”的话，Chrome的体验就会大打折扣了。由于谷歌于2010年就退出了中国市场，所以谷歌翻译、谷歌浏览器账号在国内的网络环境下基本无法使用。

## Microsoft Edge——最佳的国内体验

![Microsoft Edge](../引用图片/上网记/介绍常见浏览器/Microsoft_Edge.jpg)

Microsoft Edge 是微软基于 Chromium 开源项目及其他开源软件开发的网页浏览器。同时也是 Windows 11 自带的浏览器。

微软做浏览器的历史还挺悠久的，早在1995年微软就推出了IE浏览器，IE浏览器通过与Windows系统捆绑安装迅速占领市场，2002年全球市场份额达95%，后面因为微软疏于更新，出现了兼容性缺陷、安全漏洞及运行效率等等各种问题。于是在2015年，微软宣布逐步淘汰IE，IE的接班人就是Microsoft Edge。

最初Edge使用的内核是微软自研的Edge HTML，不过这个内核着实是一言难尽。举个例子，微软自家云服务网站 Azure 都没有支持自家浏览器内核，导致自家的员工演示的时候当场下了一个Google Chrome，详情可以看看这个：[因 Edge 连续崩溃，一微软员工在演讲中途安装 Chrome](https://www.bilibili.com/video/BV1ex411E7HJ/?share_source=copy_web&vd_source=434c03039846016c6a3a20dba7249436&t=2202)

于是乎，微软在2019年推出了基于 Chromium 的 Microsoft Edge，新版的 Edge 与 Chrome 采用了一样的内核，经过多年的发展，Edge 已经逐渐成熟了。

由于微软在中国大陆境内有很多业务，如微软账号业务、翻译业务、必应（Bing）搜索业务等，在不使用“科学上网”时，Edge 的体验在国内基本属于独一档的存在。

## Mozilla Firefox——不错的 Chromium 替代品

![[Firefox.jpg]]

Firefox 是四巨头里唯一一个**不用 Chromium 内核**的浏览器。它使用的是 Mozilla 自己开发的 Gecko 内核。

Firefox 最大的卖点是**隐私保护**和**出色的 Linux 端体验**。默认情况下，Firefox 会阻止很多追踪器跟踪你的上网行为。如果你比较在意隐私的话，Firefox 是一个很好的选择。同时，Ubuntu的默认预装浏览器就是 Firefox，由此可见 Firefox 在 Linux 上的稳定的市场占有率

## Apple Safari——苹果用户的专属

![Safari](../引用图片/上网记/介绍常见浏览器/Safari.jpg)

Safari 是苹果设备（Mac、iPhone、iPad）自带的浏览器。如果你用的是苹果全家桶，Safari 的体验是很丝滑的：

- 在 iPhone 上打开的网页，可以在 Mac 上接着看
- 比 Chrome 省电得多（特别是 MacBook 上）
- 隐私保护做得也很到位

不过 Safari 有个硬伤：**只有苹果设备能用**。Windows 上的 Safari 在很久以前就停止更新了，连浏览百度都有点费劲，所以 Windows 用户基本与 Safari 无缘。

# 常见的浏览器概念

下面煮包介绍一下使用浏览器时经常会看到的一些概念。

## 标签页（Tab）

标签页就是浏览器顶部那个一个一个小方块。你可以在一个窗口里打开多个标签页，通过点击标签来切换不同的网页。按 **Ctrl + T** 可以打开新标签页，按 **Ctrl + W** 可以关闭当前标签页。

## 书签（Bookmark）

书签就是你把喜欢的网页收藏起来，方便以后再次访问。就像在图书馆里给喜欢的书做一个记号一样。按 **Ctrl + D** 可以把当前网页添加到书签。

## 历史记录（History）

历史记录会记下你最近访问过的所有网页。如果你不小心关掉了某个重要的网页，按 **Ctrl + H** 打开历史记录就能找到它。

> [!WARNING] 
> ***隐私提示***
> 
> 如果你用的是公共电脑或者借给别人用电脑，记得清空历史记录哦。按 **Ctrl + Shift + Delete** 可以快速打开清除浏览数据的窗口。

## 无痕模式 / 隐私模式

无痕模式下，浏览器不会保存你的浏览历史、Cookie 和表单数据。按 **Ctrl + Shift + N**（Chrome/Edge）或 **Ctrl + Shift + P**（Firefox）就可以打开。

> [!warning] 
> ***常见误区：无痕模式 ≠ 匿名上网***
> 
> 很多小白以为开了无痕模式就没人知道自己在网上干什么了。其实不然，无痕模式只是不让浏览器记录你的操作，但你的**网络服务提供商（ISP）**、你访问的网站本身、还有你公司的网络管理员（如果用公司网络的话），都是能看到你在干什么的哦！

## Cookie 与缓存

Cookie 和缓存是浏览器用来**记住你**和**加快访问速度**的两个重要机制。

**Cookie** 是网站留在你浏览器里的"小纸条"。每次你访问同一个网站时，浏览器就会把这个小纸条带给网站，网站就知道"哦，是你来了"。比如你在购物网站登录了账号、把商品加入购物车，靠的都是 Cookie。不过 Cookie 不全是好东西——有些第三方 Cookie 会跟踪你浏览了哪些网页，用来给你推送"精准广告"。

**缓存** 是浏览器帮你临时存的网页"零件"——比如网站的 Logo 图片、CSS 样式文件等。当你第二次访问同一个网站时，浏览器直接从本地加载这些零件，不用重新从网上下载，打开速度会快很多。

> [!tip] 
> ***什么时候需要清 Cookie 和缓存？***
> 
> 按 **Ctrl + Shift + Delete** 打开清除浏览数据的窗口，勾选"Cookie 和其他站点数据"和"缓存的图片和文件"即可。
>
> - **Cookie**：如果你发现某个网站登录状态异常（比如明明登了却说没登），清一下 Cookie 通常能解决
> - **缓存**：如果网页显示异常（比如样式乱了、图片不更新），清一下缓存再刷新就好了
>
> 不过要注意：清了 Cookie 后，大部分网站的登录状态会丢失，需要重新登录哦。

## 扩展（Extension / Add-on）

扩展相当于给浏览器安装"外挂"，可以让浏览器做更多的事情。比如：

- **广告拦截**（如uBlock、 Adguard）：屏蔽网页广告，特别是搜索结果中出现的盗版网站
- **Dark Reader**：为部分未支持深色模式的网页提供深色模式转化
- **替代浏览器起始页的插件**（如 WeTab 等）：现在的浏览器要么起始页太简单了，要么广告满天飞，这些插件可以帮助你把起始页设置的符合你心意
- **AI集成**（如豆包等）：这些插件可以使你在不离开浏览器的情况下调用AI能力
- **开发人员工具**（如 Tampermonkey，原名油猴，现已更名篡改猴）：能扩展浏览器的能力，但不建议小白安装使用

> [!warning] 
> 大部分情况下使用浏览器提供的插件市场足够满足你的需求。不要手动安装来路不明的扩展，因为这些插件可能会窃取你的数据。

## 密码管理器

网络上经常有这么一个段子：“新密码不能与旧密码相同”。这个段子大概讲的是这样一个事：当你尝试登录一个网站时，你尝试了好几次密码都是错的，所以你尝试去重置密码，可你尝试重置密码时，网站提示“新密码不可以与旧密码相同”。但是如果你会使用浏览器的密码管理器，这就不是一个问题。

主流浏览器的最新版本基本都配备了密码生成、密码管理的功能。一般在完成新网站的注册时，浏览器会提示你是否存储此网站的账密。如果你选择同意浏览器存储这个网站的账号与密码，那当你下次再登录到这个网站时，只需要简单的认证你的生物特征（如人脸、指纹等）即可自动填充你之前设置的密码。妈妈再也不用担心我记不住密码了！
